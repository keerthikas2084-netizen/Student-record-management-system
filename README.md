
# Student Record Management System
  
   ## Project Description
   A menu-driven Student Record Management System
   developed using C programming and Singly Linked List.
  
## Features
 - Add student records
 - Delete student records
 - Display student records
 - Modify student records
 - Save records into student.dat
 - Load records from student.dat
 - Sort records by name and percentage
 - Reverse linked list
 - Delete all records
  
## Technologies
 - C Programming
 - GCC Compiler
 - Ubuntu Linux
 - Singly Linked List
 - File Handling
 - Dynamic Memory Allocation
  
## Compilation
  gcc -Wall -Wextra -std=c11 stud_main.c stud_add.c stud_del.c stud_show.c stud_mod.c stud_save.c stud_sort.c stud_reverse.c -o student
## Execution
./student
